# GIF Converter

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Десктопное приложение для конвертации видео и изображений в GIF с интуитивным редактором.

## Скачать готовую сборку
Вам не нужно собирать проект из исходников. Вы можете скачать готовый установщик (`.exe`) для Windows в разделе **[Releases](../../releases)**. 
Просто скачайте последнюю версию, установите её, и программа сразу готова к работе (FFmpeg уже встроен).

## Возможности
* Конвертация видео и изображений в GIF.
* Пакетная обработка (конвертация всего списка файлов в выбранную папку).
* Визуальный редактор обрезки (Crop) с поддержкой фиксированных пропорций (1:1, 16:9) и свободного формата.
* Поворот и отражение видео.
* Точная настройка таймлайна (выбор времени начала и конца).
* Настройка FPS, разрешения, палитры цветов и дизеринга для контроля веса файла.

## Стек технологий
* Frontend: React 18, TypeScript, Vite
* Backend: Rust, Tauri v2
* Движок конвертации: FFmpeg (встроенный)

## Сборка из исходников (для разработчиков)

Если вы хотите запустить проект локально или собрать его самостоятельно:

1. Клонируйте репозиторий.
2. Установите зависимости:
   npm install
3. Скачайте статическую сборку [FFmpeg для Windows](https://www.gyan.dev/ffmpeg/builds/) и положите файл ffmpeg.exe в папку src-tauri/.
4. Запустите проект в режиме разработки:
   npm run tauri dev
5. Для сборки релиза:
   npm run tauri build

Установочный файл появится в папке src-tauri/target/release/bundle/nsis/.
